# Operator's Manual v4 Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Archive the current v3 Operator's Manual to `operators_versioned_docs/version-3.0/` and make `versioned_docs/operators-manual/` the v4 manual, with no content changes.

**Architecture:** Use Docusaurus's own `docs:version:operators` CLI to produce the archive, then update the plugin `versions` map, the README version table, and the lint scripts. The manual stays in place and simply becomes v4; Phases 2-4 edit it there.

**Tech Stack:** Docusaurus 2.2.0, Node 18.20.4, markdownlint-cli 0.31.1.

**Design doc:** `specs/2026-09-11-operators-manual-v4-phase1-design.md`

**Branch:** `operators-manual-v4`. Do not merge — Nick owns merges.

## Context for someone with zero repo knowledge

This repo builds https://openmetal.io/docs with Docusaurus 2. There is no unit test
framework. Verification is `npm run build` exiting 0, `npm run lint` exiting 0, and
asserting that specific files exist in `build/`. Treat those as the tests.

The Operator's Manual is a **second** Docusaurus docs plugin instance, declared in
`docusaurus.config.js` under `plugins:` with `id: 'operators'`. Because its id is
`operators`, Docusaurus uses these conventional paths at repo root:

- `operators_versioned_docs/version-X.X/` — archived versions
- `operators_versioned_sidebars/version-X.X-sidebars.json` — their sidebars
- `operators_versions.json` — the list of archived version names

The *current* (unarchived) version lives at `versioned_docs/operators-manual/`, which
is set by the plugin's `path` option. That directory name is confusing but correct —
do not move it.

**Two customizations you must not break:**

1. `src/theme/DocSidebar/index.js` is a swizzled component that injects
   `src/components/SidebarVersionSelector.js` above the sidebar.
2. `sidebars/sidebarsOperators.js` has a custom `← Return To Home` link with
   `className: 'back-to-home-link'`, followed by an autogenerated category.

Neither is touched by this plan. The verification steps prove they survived.

badge when `version.name === 'current'`. The old `'v3 (Latest)'` therefore rendered as
"Version v3 (Latest) [LATEST]".
