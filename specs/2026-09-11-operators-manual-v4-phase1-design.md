# Operator's Manual v4 — Phase 1: Version Cut

Date: 2026-09-11
Branch: `operators-manual-v4`
Status: approved for planning

## Goal

Archive the current v3 Operator's Manual and make `versioned_docs/operators-manual/`
the v4 manual. Structural only — no content edits. Phases 2-4 edit v4 in place.

## Context

`versioned_docs/operators-manual/` is the "current" version, labeled `v3 (Latest)`,
served at `/operators-manual/`. Archives live in `operators_versioned_docs/version-{2.0,1.0}/`.

PCC v4 ships OpenStack 2026.1 (Gazpacho). Verified live against the demo cloud
`173.231.234.132` / `pedantic-piranha.local`:

- Kolla image tags `2026.1-ubuntu-noble`
- OVN default (`ovn_northd`, `ovn_controller`, `neutron_ovn_*`)
- `proxysql` alongside `mariadb`
- `skyline_apiserver` + `skyline_console`, `horizon` retained on :9999
- Watcher, Magnum, Aodh absent
- UFW active; ipsets `omi_whitelist` and `customer_whitelist` present

## Procedure

Follows `README.md` ("Contributing to the Operator's Manual"): latest in
`versioned_docs/operators-manual/`, older in `operators_versioned_docs/version-X.X/`.

### 1. Cut the archive

```bash
npx docusaurus docs:version:operators 3.0
```

Expected writes, and nothing else:

- `operators_versioned_docs/version-3.0/` (copy of current)
- `operators_versioned_sidebars/version-3.0-sidebars.json`
- `operators_versions.json` → `["3.0", "2.0", "1.0"]`

If the CLI writes outside those three paths, or alters `src/`, `sidebars/`, or
`docusaurus.config.js`, abort and fall back to a manual copy plus a hand-written
sidebar JSON matching `version-2.0-sidebars.json`.

### 2. Config

`docusaurus.config.js`, operators plugin block:

```js
versions: {
  current: { label: 'v4', path: '' },
  '3.0': { label: '3.0', path: 'operators_versioned_docs/version-3.0' },
  '2.0': { label: '2.0', path: 'operators_versioned_docs/version-2.0' },
  '1.0': { label: '1.0', path: 'operators_versioned_docs/version-1.0' },
},
lastVersion: 'current',
onlyIncludeVersions: ['current', '3.0', '2.0', '1.0'],
```

Current label is `'v4'`, not `'v4 (Latest)'`. `src/components/SidebarVersionSelector.js`
prefixes `Version ` when the label lacks it and appends a `LATEST` badge when
`version.name === 'current'`. `'v3 (Latest)'` therefore renders as
"Version v3 (Latest) [LATEST]". `'v4'` renders "Version v4 [LATEST]".

### 3. PDF

`openmetal-ops-manual.pdf` (9.2MB) is a v3 artifact. Keep the copy in
`operators_versioned_docs/version-3.0/`. Delete it from
`versioned_docs/operators-manual/`. Regenerate for v4 after Phase 4.

Remove any reference to it in `versioned_docs/operators-manual/` (check `_toc.md`
and `index.md`).

### 4. README table

```markdown
| PCC Version  | OpenStack Release |
|--------------|-------------------|
| 4.0 (latest) | 2026.1 (Gazpacho) |
| 3.0          | 2023.2 (Bobcat)   |
| 2.0          | Yoga              |
| 1.0          | Victoria          |
```

Also update the prose reference to `operators_versioned_docs/version-2.0` so it
mentions 3.0 as the most recent archive.

### 5. Lint the manual

`package.json` currently lints `docs/` only, so the Operator's Manual has never been
linted. Extend both scripts to cover the live manual:

```json
"lint": "markdownlint --rules lint-rules/no-generic-alt-text.js docs/ versioned_docs/operators-manual/",
"lint-fix": "markdownlint --rules lint-rules/no-generic-alt-text.js docs/ versioned_docs/operators-manual/ --fix"
```

Frozen archives stay out. Measured 2026-09-11: `versioned_docs/operators-manual/` has
1 violation, `version-2.0` has 16, `version-1.0` has 1. Linting archives would mean
editing published historical docs for no reader benefit.

Fix the single live violation — `versioned_docs/operators-manual/index.md:80`
MD047/single-trailing-newline.

Do this **after** the archive cut, so `version-3.0` stays a true snapshot of v3 as
shipped.

## Out of scope

## Risks

| Risk | Mitigation |
|---|---|
| CLI touches swizzled theme or custom sidebars | Verification step 2 and 3; fall back to manual copy |

| Repo grows ~12MB from the archive copy | Accepted; PDF excluded from v4 saves 9.2MB |
